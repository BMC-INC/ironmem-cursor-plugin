# IronMem for Cursor 0.1.1

Versioned source package for local Cursor installation, tested with IronMem 0.4.1. The ZIP contains the manifest, skills, commands, context rule, installer, validation scripts and Apache-2.0 terms. It includes no runtime executable and does not update your existing IronMem installation.

Extract the ZIP, install IronMem separately, then follow README's local installer instructions. Use an absolute binary path and keep one IronMem entry in your client. The installer preserves other MCP settings and retains an existing different plugin copy before replacement.

Package/install tests and a real stdio save-and-recall check validate this release. Marketplace approval and full graphical Cursor acceptance are not implied by publishing this archive. See docs/VALIDATION.md for the exact acceptance boundary.
